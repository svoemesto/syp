## Решение владельца 2026-10-02: сервер отдаёт рецепт, а не видео

**Инициативу выдвинул владелец, не я.** Его довод: исходники занимают много
места, держать их в интернете дорого; у пользователя исходники уже есть.

### Ответы владельца на развилки

| Вопрос | Ответ |
|---|---|
| Где анализ | Задача админа. Пользователь работает с готовой базой, которая уже всё знает |
| Что делает скрипт | Только нарезка и склейка по манифесту |
| Что с результатом | Пользователь смотрит локально, на сайт не заливает |
| Сверка файлов | `sha256` вместо `md5` |
| Доставка | Воркер на машине пользователя, как в Karaoke |
| Показ | Скрипт собирает и показывает со списком сцен |
| Порядок работ | Сначала спека и ADR, потом новый план |

### Проверенный образец

`/sm-karaoke/system/karaoke_watcher.sh` — воркер Karaoke: находит `.sh` в
каталоге, `chmod +x`, выполняет, проверяет код возврата, удаляет, пишет в
журнал, цикл с `sleep 1`. **Дыра, которую надо закрыть в SYP:** подлинность
не проверяется, а в SYP сценарий приходит из интернета — отсюда требование
FR-089c (подпись) и FR-089c-09 (сверка sha256 до нарезки).
