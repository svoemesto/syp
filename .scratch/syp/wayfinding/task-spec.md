# Первый сквозной вертикальный срез SYP — реализация по спеке

Задача классифицирована владельцем как **БОЛЬШАЯ** 2026-10-02.
Реализуется по speckit-цепочке: `speckit-specify` → **спека уходит владельцу** →
по слову владельца `speckit-plan` → `speckit-tasks` → `speckit-analyze` →
`speckit-implement`.

## Destination (из карты #221)

Сквозной вертикальный срез на **одной серии** (`GOT.S01E01`, 82 834 кадра):
от исходного `.mkv` до собранного видеофайла «Show Your Picture» в публичной
части, с прохождением всего пути — детекция границ сцен и планов, поиск
персонажей в каждом кадре, ручная доводка оператором, сборка выборки в один
файл, показ пользователю.
