# Спецификация компонента: Проверка совместимости серий

Домен: [Selection](../domain.md). Спецификация: `specs/001-first-vertical-slice/`.

## Ответственность | Responsibility

Компонент решает, можно ли собрать подборку из выбранных сцен **без
перекодирования**, и, если нельзя, объясняет это **до выдачи сценария**.

Это отдельный компонент, а не часть генерации сценария, потому что его
результат определяет, будет ли сценарий выдан вообще. Собирать подборку из
разных серий сериала разрешено (FR-086) — вопрос только в том, позволяют ли их
параметры склейку.

## Интерфейсы и Контракты | Interfaces and Contracts

- **Проверка подборки**: список сцен → признак «выдавать» либо перечень
  несовместимых серий с различающимися признаками.
- **Признаки совместимости**: перечень сравниваемых характеристик серии.

## Логика и Алгоритмы

1. **Проверка идёт по сохранённым параметрам серии**, а не по повторному опросу
   файлов: дополнительных проходов по видео не требуется, отказ приходит
   мгновенно.
2. **Сравниваются**: разрешение, кодек видео, профиль, формат пикселей,
   частокадровая база, число и параметры аудиодорожек. Расхождение любого из
   признаков означает несовместимость.
3. **Отказ внятен.** В ответе перечисляются серии и те признаки, по которым они
   различаются: «сценарий не выдан» без указания причины бесполезно, а
   «молча ухудшить качество нельзя» — прямое требование спецификации.
4. **Отказ происходит до выдачи.** Подборка, упавшая на середине из-за
   несовместимости, оставила бы пользователя с получасом напрасной работы на
   своей машине.
5. **Подборка из разных серий сериала разрешена.** Проверка сравнивает серии между
   собой, а не запрещает их различие само по себе.
6. **Округление границ — не дефект.** Фактическая граница фрагмента отличается
   от расчётной, когда граница округлилась до ключевого кадра; обе величины
   показываются пользователю заранее, а расхождение сопровождается объяснением.

## Зависимости | Dependencies

- → параметры серий: источник сравниваемых признаков.
- → карта ключевых кадров серии: источник фактических границ фрагментов.
- → `recipe-builder`: результат проверки определяет, будет ли сценарий выдан.
