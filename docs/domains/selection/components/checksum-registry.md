# Спецификация компонента: Справочник сумм исходников

Домен: [Selection](../domain.md). Спецификация: `specs/001-first-vertical-slice/`.

## Ответственность | Responsibility

Компонент держит эталонные суммы `sha256` исходных файлов серий — то, с чем
машина пользователя сверяет файл **до** нарезки.

Смысл компонента — в порядке проверки. Подмена файла, обнаруженная через час
работы, недопустима; сумма, посчитанная заранее и записанная в сценарий,
превращает час работы в минуту ожидания отказа (ADR-0009, последствие 4).

## Интерфейсы и Контракты | Interfaces and Contracts

- **Постановка пересчёта**: серия → задание с наблюдаемым состоянием и
  прогрессом по прочитанным байтам.
- **Текущая сумма**: серия → запись справочника либо указание, что её нет.
- **Пригодность серии к выдаче**: серия → признак «можно выдавать сценарий».
- **Снимок для сценария**: серия → значение суммы, которое попадёт во фрагменты
  сценария.

## Логика и Алгоритмы | Logic and Algorithms

1. **Считается один раз, заданием.** Чтение файла 5,6 ГБ — это работа, а не
   запрос; она идёт через очередь с прогрессом и с проверкой кода возврата.
2. **История сохраняется.** Пересчёт создаёт новую запись, а не заменяет
   прежнюю. Актуальная сумма ровно одна на серию; при изменении файла прежняя
   помечается устаревшей. Стирать прежнюю нельзя: по ней видно, что файл
   менялся.
3. **Без актуальной суммы сценарий не выдаётся.** Сценарий, ссылающийся на
   устаревшую или отсутствующую сумму, у пользователя упадёт на сверке. Отказ
   должен прийти на машине администратора, а не на машине пользователя.
4. **Снимок, а не ссылка.** В сценарий попадает значение на момент выдачи.
   Иначе сценарий, скачанный вчера, сегодня соответствовал бы другой сумме, и
   подпись над ним перестала бы что-либо значить.
5. **Формат значения фиксирован.** 64 шестнадцатеричных символа в нижнем
   регистре, алгоритм ровно `SHA-256`. Именно такой вывод даёт `sha256sum` на
   машине пользователя, поэтому сверка идёт без преобразований.
6. **Ошибка счёта — ошибка задания, а не пустой результат.** Ненулевой код
   завершения, обрыв, отсутствие файла: состояние `ERROR` с текстом.

## Зависимости | Dependencies

- → очередь заданий: пересчёт — задание вида `HASH` с прогрессом.
- → параметры серии: размер файла и время изменения, при которых считали.
- → `recipe-builder`: снимок суммы попадает во фрагменты сценария.
