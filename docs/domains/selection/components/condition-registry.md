# Спецификация компонента: Реестр обработчиков условий

Домен: [Selection](../domain.md). Спецификация: `specs/001-first-vertical-slice/`.

## Ответственность | Responsibility

Компонент исполняет фильтр **одним** механизмом. Обработчик типа условия
возвращает множество планов; дерево условий сводится рекурсивно: И —
пересечение множеств, ИЛИ — объединение.

Второе, не менее важное дело компонента: **неизвестный тип условия даёт явную
ошибку, а не пустой результат**. В старом проекте исполнение фильтров было
расписано вручную под каждую пару классов, и примерно из пятнадцати пар
работали пять: пустая ветка выглядела как «ничего не найдено», а не как «эта
комбинация не поддержана».

## Интерфейсы и Контракты | Interfaces and Contracts

- **Регистрация обработчика**: тип условия → обработчик, возвращающий множество
  планов.
- **Исполнение дерева**: дерево условий → множество планов, либо явная ошибка.
- **Формулировка текстом**: дерево условий → читаемая строка для пользователя.
  Текст собирается из того же дерева, по которому фильтр исполняется, — иначе
  надпись и результат могут разойтись.

## Логика и Алгоритмы

1. **Нет пар «объект × признак» вне реестра.** Добавление нового типа условия —
   это регистрация одного обработчика, а не новая пара запросов. Обход
   реестра структурно невозможен: обработчика нет — значит, выполнить условие
   нечем.
2. **Глубина не усекается молча.** Больше трёх уровней вложенности — отказ с
   текстом, а не тихое упрощение дерева.
3. **Белый список типов условий проверяется при сохранении** и повторно при
   исполнении. Тип вне списка отвергается текстом, а не превращается в пустой
   результат.
4. **Сведение рекурсивно.** Пересечение и объединение множеств планов; видно, на
   каком уровне множество опустело, — это и есть диагностический след.
5. **Обратное отображение — один раз, при выдаче.** Исполнитель возвращает
   планы; список сцен получается как «сцена включена, если хотя бы один её
   план прошёл». Исполнитель не обязан знать про сцены.
6. **Текстовая формулировка собирается из того же дерева.** Расхождение между
   надписью и результатом невозможно по построению, а не по проверке.

## Зависимости | Dependencies

- → планы и сцены: источник множеств планов и обратного отображения.
- → персоны, места действия, размеры планов: данные для обработчиков условий.
- → `recipe-builder`: исполненный фильтр даёт список сцен для сценария.
