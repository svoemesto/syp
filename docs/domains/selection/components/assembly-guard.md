# Спецификация компонента: Проверка совместимости сборки

Домен: [Selection](../domain.md). Спецификация: `specs/001-first-vertical-slice/`.

## Ответственность | Responsibility

Компонент решает, можно ли собрать подборку из выбранных сцен **без
перекодирования**, и, если нельзя, объясняет это **до начала работы**.

Это отдельный компонент, а не часть нарезки, потому что его результат
определяет, будет ли вообще создано задание.

## Интерфейсы и Контракты | Interfaces and Contracts

- **Проверка подборки**: список сцен → признак «собирается» либо перечень
  несовместимых серий с различающимися признаками.
- **Признаки совместимости**: перечень сравниваемых характеристик серии.
- **Смещение границ**: серия, номер кадра → фактическая граница фрагмента
  после округления до ближайшего ключевого кадра.

## Логика и Алгоритмы

1. **Проверка идёт по сохранённым параметрам серии**, а не по повторному
   опросу файлов: дополнительных проходов по видео не требуется, отказ
   приходит мгновенно.
2. **Сравниваются**: разрешение, кодек видео, профиль, формат пикселей,
   частокадровая база, число и параметры аудиодорожек. Расхождение любого из
   признаков означает несовместимость.
3. **Отказ внятен.** В ответе перечисляются серии и те признаки, по которым они
   различаются: «сборка отменена» без указания причины бесполезно, а
   «молча ухудшить качество нельзя» — прямое требование спецификации.
4. **Отказ происходит до постановки задания.** Сборка, упавшая на середине
   из-за несовместимости, оставила бы половину работы и время ожидания
   впустую.
5. **Подборка из разных серий сериала разрешена.** Проверка сравнивает серии
   между собой, а не запрещает их различие само по себе.
6. **Округление границ — не дефект.** Фактическая граница фрагмента отличается
   от расчётной, когда граница округлилась до ключевого кадра; обе величины
   сохраняются и показываются, а расхождение сопровождается объяснением
   причины.

## Зависимости | Dependencies

- → параметры серий: источник сравниваемых признаков.
- → карта ключевых кадров серии: источник фактических границ фрагментов.
- → `assembly`: результат проверки определяет, будет ли задание создано.
