# Спецификация компонента: Генератор сценария сборки

Домен: [Selection](../domain.md). Спецификация: `specs/001-first-vertical-slice/`.

## Ответственность | Responsibility

Компонент превращает набор выбранных сцен в **исполняемый сценарий сборки**:
список фрагментов с относительными путями и границами по номерам кадров, плюс
снимок данных сцен для локального показа.

Компонент **не производит видео**. Он пишет текст. Нарезкой и склейкой
занимается машина пользователя (ADR-0009), поэтому в компоненте нет ни одного
вызова программы нарезки и ни одного поля, куда класть готовый файл.

## Интерфейсы и Контракты | Interfaces and Contracts

- **Проверка перед выдачей**: набор сцен → признак «выдавать» либо перечень
  причин отказа. Проверки идут в порядке возрастания цены отказа для
  пользователя и не требуют проходов по видео.
- **Сборка сценария**: набор сцен → канонические байты сценария. Результат
  воспроизводим побайтово: одни и те же данные дают одни и те же байты.
- **Фактические границы фрагмента**: серия, номер кадра → граница после
  округления до ближайшего ключевого кадра.
- **Ожидаемые величины**: сценарий → расчётная длительность и число кадров по
  сумме фактических границ.

## Логика и Алгоритмы | Logic and Algorithms

1. **Порядок проверок до выдачи.** Список не пуст; серии разбираемы; серии
   совместимы; у всех серий есть актуальная сумма. Каждая проверка отвечает
   своим кодом ошибки и перечислением объектов — молчаливый отказ недопустим.
2. **Отказ раньше, чем пользователь узнает о проблеме.** Проверка совместимости
   идёт по метаданным, сохранённым при приёме серий: дополнительных проходов по
   видео не требуется, ответ приходит мгновенно.
3. **Пути относительные и не выходят за пределы дерева.** Путь строится от корня
   сериала и проверяется на отсутствие абсолютности и выхода вверх. Сценарий,
   уводящий воркер за пределы копии сериала, — не подборка, а ошибка выдачи.
4. **Обе пары границ.** Расчётные границы берутся из разметки; фактические
   считаются по карте ключевых кадров серии: начало — ближайший ключевой кадр не
   позже начала плана, конец — не раньше конца. Пользователь видит округление
   заранее, а не после работы (ADR-0006, FR-082).
5. **Снимок данных сцены.** Место действия и имена персонажей копируются в
   каждый фрагмент. Правка справочника после выдачи не должна «слепить» уже
   скачанный сценарий, а локальный показ работает без сервера.
6. **Сумма источника — снимок.** В сценарий попадает значение справочника на
   момент выдачи. Сценарий, выданный по одной сумме, нельзя освежить задним
   числом: пользователь сверяет файл с той суммой, которую видел.
7. **Канонический выход.** Фиксированный порядок полей, отсутствие лишних
   пробелов, единые переводы строк, никаких пустых полей. Это не вкус: подпись
   ставится над этими байтами, и без канонизации проверка не воспроизводится.
8. **Версия формата** попадает в сценарий. Смена версии помечает ранее выданные
   сценарии устаревшими, а воркер отвергает незнакомую версию прямо, вместо
   того чтобы разбирать незнакомую структуру.

## Зависимости | Dependencies

- → `condition-registry`: список сцен приходит из исполненного фильтра.
- → `checksum-registry`: эталонные суммы исходников; без них сценарий не
  выдаётся.
- → `recipe-compatibility`: проверка совместимости серий до выдачи.
- → `recipe-signer`: подпись канонических байтов.
- → границы сцен и планов: источник номеров кадров.
- → карта ключевых кадров серии: источник фактических границ.
