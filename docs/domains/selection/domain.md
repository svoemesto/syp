# Домен Selection — Фильтры и сборка

## Обзор контекста (Bounded Context)

Отвечает на вопрос «покажи мне сцены с таким персонажем в таком месте» и
собирает найденное в один видеофайл. Фильтры сохраняются и переиспользуются.

## Dependencies | Зависимости

- Characters — персоны для условий фильтра.
- Annotation — локации и размеры плана.
- Analysis — сцены и планы для сборки.

## Ubiquitous Language | Единый язык

| Термин | Значение |
|---|---|
| **Условие** | Один предикат: персонаж, локация, тип плана, размер, границы, наличие лица. |
| **Фильтр** | Именованное дерево условий, до трёх уровней, на каждом свой И/ИЛИ. |
| **Подборка** | Набор сцен, выбранный фильтром. |
| **Сборка** | Видеофайл из сцен подборки, созданный на сервере. |
| **Округление на стыке** | Захват лишнего кадра при склейке без перекодирования. |

## Публичные контракты (API)

Определяются в `speckit-plan`: построение фильтра, сохранение и повторное
применение, выбор сцен, запуск сборки, получение результата.

## Domain Invariants | Инварианты и правила бизнеса

1. Фильтр выполняется **одним универсальным механизмом**, а не отдельной
   логикой под каждое сочетание условий.
2. Сборка не перекодирует видео: качество исходника сохраняется.
3. Расчётная и фактическая длительность сборки показываются обе, если разошлись.
4. Несовместимые по параметрам серии отклоняются **до** начала работы.

## Структура компонентов (C4 L3)

Состав определён планом первого сквозного среза
(`specs/001-first-vertical-slice/plan.md`, фазы 8 и 9).

| Компонент | Ответственность | Статус |
|---|---|---|
| `filter-builder` | Построение дерева условий: три уровня, на каждом свой И или ИЛИ. | спецификация не написана |
| `filter-store` | Сохранение, повторное применение, правка, удаление. | спецификация не написана |
| [condition-registry](components/condition-registry.md) | Единый исполнитель фильтра: реестр обработчиков типов условий, сведение дерева, явная ошибка на неизвестный тип. | спецификация написана |
| `assembly` | Нарезка фрагментов и склейка без перекодирования, измерение фактической длительности. | спецификация не написана |
| [assembly-guard](components/assembly-guard.md) | Проверка совместимости серий до начала работы и округление границ до ключевого кадра. | спецификация написана |

Исполнение сборки живёт в бэкенде публичной части, а не админки: инициатором
сборки является пользователь. Общая инфраструктура определена в
[`contracts/job-queue.md`](../../../specs/001-first-vertical-slice/contracts/job-queue.md).
