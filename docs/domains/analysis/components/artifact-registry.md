# Спецификация компонента: Хранилище и реестр артефактов

Домен: [Analysis](../domain.md) — артефактами являются листы превью и модели;
канонические байты сценариев обслуживает [Selection](../../selection/domain.md),
но состояния и правила атомарности общие. Спецификация:
`specs/001-first-vertical-slice/`, модель данных, раздел 2.18.

## Ответственность | Responsibility

Компонент регистрирует результат задания в хранилище и даёт атомарность:
пока состояние не `READY`, артефакт не считается готовым и не может быть
использован ни сборкой, ни показом, ни проверкой готовности серии (FR-091).

## Интерфейсы и Контракты | Interfaces and Contracts

- **Открыть запись**: вид артефакта, окончательный ключ → запись в состоянии
  `WRITING` с временным ключом записи.
- **Записать содержимое**: запись артефакта, поток данных.
- **Завершить**: запись, контрольная сумма, размер → перенос временного объекта
  на окончательный ключ и состояние `READY`.
- **Пометить неудачным**: запись, причина → удаление временного объекта и
  состояние `FAILED`.
- **Прочитать готовый**: идентификатор артефакта → поток содержимого. Чтение
  артефакта не в состоянии `READY` отклоняется.
- **Проверить готовность**: вид и ключ → запись в состоянии `READY` либо
  «не найдено».

## Логика и Алгоритмы | Logic and Algorithms

1. **Три состояния**: `WRITING`, `READY`, `FAILED`.
2. **Сначала временный ключ, потом окончательный.** Артефакт пишется по
   временному ключу и переносится на окончательный **только** после нулевого
   кода завершения всех внешних программ задания и проверки результата.
   Регистрация `READY` выполняется **после** переноса.
3. **`READY` без временного объекта получить нельзя.** Метод завершения
   сначала убеждается, что временный объект существует, и только потом
   переносит его: незавершённый файл не считается готовым.
4. **При сбое временный объект удаляется**, запись переходит в `FAILED`:
   оборванный лист превью на SSD не нужен никому.
5. **Размещение только `SSD`.** Значения `HDD` нет и не появится без новой
   миграции и нового решения владельца: готовые видеофайлы на сервере не
   хранятся, они остаются у пользователя (ADR-0009, FR-021, Д-8).
6. **Виды артефактов — три**: `PREVIEW_SHEET`, `MODEL`, `RECIPE`. Вида
   `ASSEMBLY` и `CUT_FRAGMENT` не существует по той же причине.
7. **Контрольная сумма — SHA-256** в виде 64 шестнадцатеричных символов в
   нижнем регистре; ограничение задано на уровне таблицы, поэтому «записали
   как получилось» в базу не попадает.
