# Домен Characters — Лица и персонажи

## Обзор контекста (Bounded Context)

Находит **лица в каждом кадре**, группирует похожие в кластеры и учит
распознаванию на эталонах. Даёт ответ на вопрос «кто в кадре и где он».

## Dependencies | Зависимости

- Analysis — кадры и принадлежность кадра плану.
- Annotation — имена и метки «эталон» от оператора.

## Ubiquitous Language | Единый язык

| Термин | Значение |
|---|---|
| **Лицо** | Прямоугольник в кадре с привязкой к плану. |
| **Персона** | Именованная личность; идентичность не зависит от отображаемого имени. |
| **Кластер** | Группа похожих лиц без имени; оператор даёт имя. |
| **Эталон** | Лицо, помеченное для обучения. |
| **Версия модели** | Результат одного обучения: дата, число эталонов, состав классов. |
| **Неопознанное лицо** | Лицо без подтверждённой персоны; не теряется при операциях. |
| **Положение в кадре** | Рамка лица и принадлежность плану. Ракурс в первый срез не входит. |

## Публичные контракты (API)

Определяются в `speckit-plan`: поиск лиц в кадре, кластеризация, обучение,
чтение и откат версий модели.

## Domain Invariants | Инварианты и правила бизнеса

1. Лица ищутся в **каждом** кадре серии.
2. У каждого распознанного лица хранится версия модели, которой оно опознано.
3. Предыдущие версии модели сохраняются; откат возможен.
4. Неопознанные лица не исчезают при переобучении и удалении персон.
5. Переименование персоны не ломает модель.

## Структура компонентов (C4 L3)

Состав определён планом первого сквозного среза
(`specs/001-first-vertical-slice/plan.md`, фазы 3 и 7).

| Компонент | Ответственность | Статус |
|---|---|---|
| `face-detection` | Поиск лиц в каждом кадре серии на видеокарте, без записи кадров на диск. | спецификация не написана |
| `face-embedding` | Векторные представления лиц, хранение отдельно от строки лица. | спецификация не написана |
| `face-clustering` | Группировка похожих лиц в кластеры без обученной модели. | спецификация не написана |
| [model-training](components/model-training.md) | Обучение на эталонах, версии, переопознавание, откат. | спецификация написана |

Общая инфраструктура — очередь заданий, исполнитель внешних программ —
определена в
[`contracts/job-queue.md`](../../../specs/001-first-vertical-slice/contracts/job-queue.md).
