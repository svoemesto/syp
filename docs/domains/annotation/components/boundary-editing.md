# Спецификация компонента: Доводка границ

Домен: [Annotation](../domain.md). Спецификация: `specs/001-first-vertical-slice/`.
Происхождение: план `007-speckit-plan-recipe`, перенесено из плана
`004-speckit-plan` без изменения содержания: схема «рецепт» (ADR-0009) этих
компонентов не касается.

## Ответственность | Responsibility

Компонент отвечает за **вмешательство человека в результат автоматики**:
разделение и объединение планов, отмену решения алгоритма, а также
согласованность того, что после этого вмешательства изменилось в данных.

Ключевая обязанность — **согласованность**. Правка границы меняет не одну
строку: меняются принадлежность лиц планам и, если граница попала внутрь
сцены, сама сцена.

## Интерфейсы и Контракты | Interfaces and Contracts

- **Разделить план**: эпизод, номер кадра внутри плана → два плана и
  обновлённая структура затронутого участка.
- **Объединить планы**: эпизод, номер кадра на границе → один план и
  обновлённая структура затронутого участка.
- **Отменить решение алгоритма**: эпизод, номер кадра → граница помечена
  отменённой, происхождение изменено.
- **Исправить размер плана**: план, значение → размер изменён, происхождение
  размера — «сделано оператором».
- **Признать правку сохранённой автоматически**: отдельного метода «сохранить»
  нет; ответ приходит сразу после операции.

## Логика и Алгоритмы

1. **Разделение.** План, внутри которого указан кадр, делится на два: первый
   заканчивается кадром перед указанным, второй начинается с указанного.
   Новый план наследует происхождение исходного.
2. **Объединение.** План, начинающийся в указанном кадре, поглощается
   предыдущим; его размер пересчитывается, потому что наибольшее лицо могло
   уйти в поглощённую часть.
3. **Согласование сцен.** Если новая граница оказалась внутри сцены, сцена
   разрезается или сокращается по правилу «сцена — максимальный непрерывный
   ряд планов». Разрезание выполняется в одном изменении с правкой плана.
4. **Пересчёт принадлежности лиц.** В той же операции лица затронутого
   диапазона переводятся на тот план, чей диапазон их теперь содержит.
   Инвариант проверяется тестом: после любой операции принадлежность лица
   совпадает с правилом диапазонов.
5. **Происхождение границы — состояние, а не флаг.** Значение «решение
   алгоритма отменено» — самостоятельное состояние, а не отсутствие границы.
   Поэтому отмена переживает повторный анализ: решение человека есть
   решение, а не отсутствие данных.
6. **Повторный анализ не отменяет ручное.** Анализ обновляет сырой результат и
   добавляет новое, но не трогает рабочие границы, помеченные как сделанные
   или отменённые человеком.
7. **Ответ содержит результат операции.** Интерфейс не перезапрашивает всё
   дерево: возвращается обновлённый участок с пересчитанными размерами,
   принадлежностями и признаками.

## Зависимости | Dependencies

- → `boundary-store`, `scene-detection`, `shot-detection`: хранение и
  пересчёт границ.
- → `face-detection`: пересчёт принадлежности лиц планам.
- → параметры фильма: пороги размера плана при пересчёте.
