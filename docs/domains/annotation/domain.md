# Домен Annotation — Разметка оператором

## Обзор контекста (Bounded Context)

Место, где человек вмешивается в результат автоматики: правит границы планов,
рисует пропущенные лица, даёт имена кластерам, назначает место действия сцены
и помечает эталоны. Ручная доводка здесь — основная функция, а не
дополнение.

## Dependencies | Зависимости

- Analysis — границы сцен и планов.
- Characters — лица, кластеры, эталоны.
- Catalog — справочник локаций сериала.

## Ubiquitous Language | Единый язык

| Термин | Значение |
|---|---|
| **Доводка границы** | Разделение плана или объединение соседних планов. |
| **Место действия** | Локация сцены из справочника сериала; назначается вручную. |
| **Размер плана** | Крупность: NONE, ECU, BCU, CU, MCU, MS, MLS, LS, VLS, XLS. |
| **Происхождение границы** | Автоматика или человек — определяет цвет оверлея. |
| **Отмена решения автоматики** | Помечается отдельно от «сделано человеком». |
| **Автосохранение** | Правка сохраняется без кнопки; повторный анализ её не стирает. |

## Публичные контракты (API)

Определяются в `speckit-plan`: доводка границ, рисование лица мышью,
назначение персоны перетаскиванием, назначение локации, метки «эталон».

## Domain Invariants | Инварианты и правила бизнеса

1. Ручная правка **не теряется** при повторном анализе.
2. Место действия сцены определяется **только вручную**.
3. Распознавание ракурса лица в первый срез **не входит**.
4. Правка сохраняется автоматически, без кнопки «Сохранить».

## Структура компонентов (C4 L3)

Состав определён планом первого сквозного среза
(`specs/001-first-vertical-slice/plan.md`, фазы 5 и 6). Это ядро продукта:
объём ручной работы задан решением владельца Д-6 и резать его можно только
его словом.

| Компонент | Ответственность | Статус |
|---|---|---|
| [boundary-editing](components/boundary-editing.md) | Разделение и объединение планов, отмена решения алгоритма, согласование сцен и принадлежности лиц. | спецификация написана |
| `face-drawing` | Рисование пропущенного лица мышью с пометкой «сделано человеком». | спецификация не написана |
| `person-assignment` | Назначение лица персоне перетаскиванием, пометка и снятие метки эталона. | спецификация не написана |
| `location-assignment` | Назначение места действия сцены из справочника сериала. | спецификация не написана |

Сохранение ручных правок при повторном анализе обеспечивается компонентом
[analysis-run](../analysis/components/analysis-run.md) и тем, что задание
анализа не трогает рабочие границы, помеченные как сделанные или отменённые
человеком.

Общая инфраструктура определена в
[`contracts/job-queue.md`](../../../specs/001-first-vertical-slice/contracts/job-queue.md).
