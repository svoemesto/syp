# Домен Showcase — Публичная часть

## Обзор контекста (Bounded Context)

То, что видит пользователь: выбирает фильтр, отмечает сцены, запускает сборку
и смотрит готовое видео. Здесь **нет** разметки, обучения и настройки — только
просмотр результата.

## Dependencies | Зависимости

- Selection — фильтры и сборка.

## Ubiquitous Language | Единый язык

| Термин | Значение |
|---|---|
| **Подборка пользователя** | Набор сцен, выбранный самим пользователем. |
| **Задание сборки** | Задание очереди с прогрессом и результатом по адресу подборки. |
| **Готовое видео** | Собранный файл со списком вошедших сцен. |

## Публичные контракты (API)

Определяются в `speckit-plan`: список сериалов, применение фильтра, выбор
сцен, запуск сборки, просмотр результата.

## Domain Invariants | Инварианты и правила бизнеса

1. Сборку инициирует **пользователь**, а не оператор.
2. Публичная часть не выполняет разметку и не обучает модели.
3. Повторное открытие страницы не теряет запущенное задание.
4. Аутентификация в первый срез не входит: стек локальный.

## Структура компонентов (C4 L3)

| Компонент | Ответственность |
|---|---|
| `filter-picker` | Выбор фильтра и сцен. |
| `assembly-launch` | Запуск сборки и наблюдение за заданием. |
| `player` | Воспроизведение готового видео. |
