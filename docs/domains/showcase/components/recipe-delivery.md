# Спецификация компонента: Выдача сценария

Домен: [Showcase](../domain.md). Спецификация: `specs/001-first-vertical-slice/`.

## Ответственность | Responsibility

Компонент отдаёт пользователю **файл сценария** и всё, что нужно для его
проверки: подпись, сумму содержимого и открытый ключ.

Компонент **не отдаёт видео** — ни файла, ни потока, ни ссылки на него. В этом
компоненте нет ни одного эндпоинта с видеосодержимым, и это не запрет в
договорённостях, а отсутствие (FR-088, ADR-0009).

## Интерфейсы и Контракты | Interfaces and Contracts

- **Выбор сцен и заявка**: набор сцен → сценарий либо внятный отказ.
- **Скачивание файла сценария**: сценарий → файл в канонической форме.
- **Подпись и ключ**: сценарий → подпись, сумма содержимого, идентификатор
  ключа; открытый ключ проверки.
- **Состав сценария для показа**: сценарий → перечень фрагментов с границами и
  данными сцен.

## Логика и Алгоритмы

1. **Инициатор — пользователь.** Оператор в админке подготавливает данные, но
   сценарий за пользователя не выдаёт: в админке есть только чтение.
2. **Отказ внятен и приходит сразу.** Несовместимые серии, отсутствие
   актуальных сумм, неразобранная серия — каждый случай даёт свой код и
   перечень объектов.
3. **Отдаётся только готовое.** Файл сценария отдаётся лишь тогда, когда
   артефакт в состоянии `READY`: незавершённый файл не считается готовым
   (FR-091).
4. **Доставка ручная.** Пользователь сохраняет файл браузером и сам кладёт его
   в папку сценариев. Автоматической доставки, ссылок с подпиской,
   автообновления и докачивания в первом срезе нет — это сознательное
   ограничение объёма, а не недоработка.
5. **Пользователь видит округление заранее.** В составе сценария показываются
   обе пары границ фрагмента, поэтому решение «устраивает меня округление или
   нет» принимается до работы, а не после.
6. **Прогресс задания не теряется при перезагрузке страницы**: сценарий — ресурс
   с адресом, а не состояние вкладки.

## Зависимости | Dependencies
