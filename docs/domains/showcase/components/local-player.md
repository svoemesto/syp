# Спецификация компонента: Локальный показ

Домен: [Showcase](../domain.md). Спецификация: `specs/001-first-vertical-slice/`.

## Ответственность | Responsibility

Компонент показывает готовый файл **на машине пользователя**: со списком вошедших
сцен и перемоткой между ними по названиям, персонажам и местам действия.

Сайт в показе не участвует. Ни одного сетевого запроса во время просмотра быть
не должно: если локальная страница требует сеть, сценарий не самодостаточен, и
это дефект, а не особенность режима.

## Интерфейсы и Контракты | Interfaces and Contracts

- **Карта глав**: результат сборки → главы с названиями, встраиваемые в файл.
- **Локальная страница**: сценарий и результат сборки → страница со списком
  сцен и перемоткой.
- **Запуск показа**: → открытие показа в браузере пользователя.

## Логика и Алгоритмы

1. **Главы встраиваются в сам файл** потоковым копированием. Перекодирования
   нет (ADR-0006), поэтому добавление глав не портит качество и не требует
   пересборки потока.
2. **Времена глав считаются по измеренным длительностям фрагментов**, а не по
   расчётным: после склейки фактические границы известны точно, и глава должна
   попадать в начало своей сцены.
3. **Страница решает то, чего не решают главы.** Главы дают перемотку в любом
   плеере, но не дают читаемых названий: список сцен с названием, персонажами и
   местом действия делается отдельной локальной страницей.
4. **Данные берутся из сценария и результата**, а не с сервера. Место действия и
   имена персонажей в сценарии — снимок на момент выдачи.
5. **Показ запускается по итогам сборки** и по явному действию пользователя. При
   каждом старте воркера показ сам не поднимается: пользователь запустил
   воркер не затем, чтобы каждый раз смотреть одно и то же.
6. **Ничего не уходит наружу.** Ни файл, ни страница, ни отчёт о выполнении на
   сайт не отправляются (FR-089e).

## Зависимости | Dependencies

- → `local-worker`: результат сборки, измеренные длительности фрагментов.
- → сценарий сборки: названия сцен, персонажи, места действия, границы.
- → `ffmpeg`: встраивание глав потоковым копированием.
