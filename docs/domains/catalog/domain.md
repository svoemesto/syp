# Домен Catalog — Сериалы и серии

## Обзор контекста (Bounded Context)

Отвечает за то, **что** вообще обрабатывается: произведения (сериалы) и их
составные видеофайлы (серии). Хранит параметры файла и путь к источнику.
Не знает о сценах, лицах и подборках.

## Dependencies | Зависимости

- Внешний источник: архив видео `/disks/HDD_16Tb_Clouds/GOT` — **только
  чтение**, система ничего в нём не изменяет.
- Домен Analysis читает параметры серии отсюда.

## Ubiquitous Language | Единый язык

| Термин | Значение |
|---|---|
| **Сериал** | Произведение, с которым работают: название, список серий, справочник локаций. |
| **Серия** | Один видеофайл сериала — файл с серией сезона. |
| **Параметры серии** | Число кадров, частокадровая база (`time_base`), разрешение, длительность, кодек. |
| **Номер кадра** | Единственный источник правды для границ; время производно от него. |
| **Источник** | Путь к исходному видеофайлу; файл только читается. |

## Публичные контракты (API)

Определяются в `speckit-plan`. Контракты: создание сериала, добавление серии,
чтение параметров.

## Domain Invariants | Инварианты и правила бизнеса

1. Номер кадра — единственный источник правды для границ; время пересчитывается
   от `time_base` конкретной серии.
2. Исходные видеофайлы **никогда не изменяются**.
3. Одна серия принадлежит ровно одному сериалу.
4. Серии одного сериала могут отличаться параметрами видео — совместимость
   проверяется перед сборкой, а не предполагается.

## Структура компонентов (C4 L3)

Состав определён планом первого сквозного среза
(`specs/001-first-vertical-slice/plan.md`, фазы 0 и 1). Спецификации
компонентов появляются по мере реализации.

| Компонент | Ответственность | Статус |
|---|---|---|
| `series-import` | Регистрация серии: опрос файла и сохранение параметров, включая карту ключевых кадров. | спецификация не написана |
| `serial-registry` | Сериалы, справочник мест действия, связи с сериями. | спецификация не написана |
| `analysis-settings` | Пороги и параметры анализа сериала, создание настроек по умолчанию, помечение результата устаревшим при их изменении. | спецификация не написана |

Общая инфраструктура — очередь заданий, исполнитель внешних программ,
хранилище — определена в
[`contracts/job-queue.md`](../../../specs/001-first-vertical-slice/contracts/job-queue.md)
и не относится к одному домену.
