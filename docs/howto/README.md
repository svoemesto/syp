# Каталог плейбуков (How-to)

Плейбук — это **кросс-доменная пошаговая процедура**: как выполнить
конкретную задачу средствами нескольких доменов. В отличие от `guidelines`
(паттерны и ограничения), плейбук — исполнимый рецепт.

**Правила размещения**:

- один каталог на плейбук: `howto/<slug>/playbook.md`;
- плейбук **не размещается** внутри `domains/<домен>/components/`: там
  фиксируется возможность или инвариант, а не рецепт;
- каждый плейбук обязан содержать раздел «Зависимости (домены/компоненты)»
  со ссылками только на существующие домены;
- каждый плейбук перечислен в этом каталоге и в `docs/README.md`.
