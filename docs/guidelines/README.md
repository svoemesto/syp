# Guidelines

Стандартные паттерны и ограничения, действующие во всех доменах: конвенции
именования, правила доступа к данным, ограничения по ресурсам.

Отличие от плейбуков: guideline говорит «как принято делать», плейбук —
«как выполнить конкретную задачу по шагам». Рецепты живут в `../howto/`.

## Документы

| Документ | О чём |
|---|---|
| [sse-notifications](sse-notifications.md) | Нотификации интерфейса одним потоком SSE: вкладки, типы событий, сердцебие, обрыв и переподключение |

Планируемые документы: конвенции архитектуры и сборки (упомянуты в
`AGENTS.md` как обязательные), правила работы с очередью заданий, правила
проверки подпроцессов.
