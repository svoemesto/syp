# Public

Человекочитаемые проекции внутренней документации — для внешних потребителей
или для людей вне проекта.

**Это выходы, а не источники**: для технического исследования и разбора сбоев
ими не пользуются, читают `../domains/`.

Планируется: описание того, что видит пользователь публичной части, без
внутренних деталей реализации.

Пока документов нет.
