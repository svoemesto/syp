# Сверка параметров эпизода с измеренными

**Задача**: T038. **Дата замера**: 2026-10-04. **Эпизод**: `GOT.S01E01`.

## Что мерили

Совпадают ли параметры эпизода, которые система определяет сама при регистрации,
с тем, что даёт прямой замер того же файла тем же `ffprobe`, — и с числами,
зафиксированными в спецификации.

Сверка двумя независимыми способами, а не одним: расхождение показывает,
чьё оно — системы или измерения.

## На чём мерили

| Что | Значение |
|---|---|
| Файл | `/disks/HDD_16Tb_Clouds/GOT/GOT.S01/GOT.S01E01.BDRip.1080p.mkv` |
| Размер | 5 598 286 865 байт, время изменения 2024-11-05 13:34:28 +0300 |
| Программа | `ffprobe` 6.1.1-3ubuntu5, из `/usr/bin` (та же, что требуется контейнеру `syp-admin-app`) |
| Код системы | `SourceProbe` (`syp-admin-app/.../catalog/SourceProbe.kt`), проверка `EpisodeParametersParityTest` |
| Число прогонов | по одному прогону каждого прохода; разброс не измерялся, потому что все проходы **детерминированные**: считают пакеты и читают отметки времени, а не меряют скорость |
| Среда | агентская сессия машины `nsa-i9`; `ffprobe` читал заголовок и считал пакеты без декодирования изображения |

**Замер без декодирования.** Здесь нет пайплайна видео: `ffprobe` читает
заголовок, считает пакеты (`-count_packets`) и читает отметки только ключевых
кадров (`-skip_frame nokey`). Декодирования изображения не было, поэтому
оговорка про обрыв `ffmpeg` по `signal 9` на длинных операциях здесь не
применима. Время проходов приведено рядом — оно и показывает, что это были
короткие операции.

## Какое число получили

Прямой замер и параметры системы совпали по всем трём величинам:

| Величина | Прямой замер `ffprobe` | Система | Совпало |
|---|---|---|---|
| Число кадров (`-count_packets`) | 88 643 | 88 643 | да |
| Ключевых кадров (`-skip_frame nokey`) | 792 | 792 | да |
| Размер файла (`format=size`) | 5 598 286 865 байт | 5 598 286 865 байт | да |

Остальные параметры эпизода (сверялись с числами спецификации):

| Параметр | Значение системы |
|---|---|
| Разрешение | 1920 × 1080 |
| Частокадровая база | 1001/24 000 с на кадр, то есть 24000/1001 кадра в секунду |
| Кодек, профиль, формат пикселей | `h264`, `High`, `yuv420p` |
| Звук | `ac3`, 6 каналов, 48 000 Гц |
| Длительность по кадрам | **3697,152 с** |
| Длительность, объявленная контейнером | 3697,184 с |
| Карта ключевых кадров | 792 бита, 11 081 байт (`ceil(88643 / 8)`) |

Время проходов: заголовок — доли секунды; подсчёт видеопакетов — **25,94 с**;
чтение ключевых кадров — **34,96 с**. Оба прохода обходят файл целиком, но
ничего не декодируют, поэтому укладываются в десятки секунд на файле 5,6 ГБ.

### Расхождение, которое обязано быть

Контейнер объявляет длительность 3697,184 с, по кадрам получается 3697,152 с.
Разница **0,032 с**, то есть 0,77 кадра.

Округление объявленной длительности до целого кадра даёт
`3697,184 × 24000/1001 = 88 643,78`, то есть **88 644 кадра — на один больше
фактического**. Именно поэтому число кадров берётся счётчиком пакетов, а не
длительностью: расхождение в один кадр разъезжается по всем границам сцен и
планов (ADR-0001). Проверка на это расхождение встроена в тест: длительность
по кадрам обязана лежать в полосе 3697,0…3697,5 с, а не совпадать с
контейнерной.

## Каким критерием проверяется

- **FR-002**: параметры эпизода определяются системой, а не вводятся оператором.
- **ADR-0001**: номер кадра — единственный источник правды; время вычисляется,
  а не хранится.
- Критерий фазы 1 плана: «эпизод `GOT.S01E01` зарегистрирована, её параметры
  совпадают с измеренными (88 643 кадра, 1920×1080, 23,976 fps, 3697,2 с)».

**Вывод: выполнено.** Все три независимо измеримые величины совпали с
системными; числа спецификации подтверждены; расхождение с контейнерной
длительностью объяснено и не влияет на модель.

## Как повторить

```bash
SYP_SOURCE_EPISODE=/disks/HDD_16Tb_Clouds/GOT/GOT.S01/GOT.S01E01.BDRip.1080p.mkv \
GRADLE_USER_HOME=/home/nsa/syp/.gradle \
  ./gradlew :syp-admin-app:test --tests '*EpisodeParametersParityTest*' --rerun-tasks -i
```

Без переменной `SYP_SOURCE_EPISODE` проверка **пропускается**, а не падает:
файла эпизода на машине может не быть.
