**Задача**: T060. **Дата сверки**: 2026-10-04. **Эпизод**: `GOT.S01E01`.

## Что мерили

Совпадают ли границы, которые наша система находит автоматикой, с 1028
эталоными планами старого проекта iGOT: сколько границ совпало, сколько
разошлось, сколько мы предложили лишних. Расхождение подписывается числом,

### Границы сцен

Сверка невозможна: файл `GOT.S1E1_Scenes.csv` хранит порядковый номер и
название сцены, но **не границы кадров**. В старом проекте 46 названных сцен.
Число наших сцен при пороге 8 — 818; сопоставить их по положению с чем-либо
нечем, и подставлять «818 против 46» как расхождение было бы выдуманным
сравнением: сцена в нашей модели — это участок между монтажными склейками, а
в старом проекте — названный фрагмент, привязанный к смыслу.

## Каким критерием проверяется

Критерий задачи T060: «расхождение подписывается числом, а не ощущением»,
и сверка доступна по объёму 71 005 сегментов на 73 эпизоде.

**Вывод: сверка выполнена, расхождение подписано числом.**

1. **Покрытие эпизода корректно**: сцены и планы покрывают все 88 643 кадра от 0
   до 88 642 без разрывов и перекрытий. Это подтверждает требование FR-011 на
   реальном эпизоде, а не на синтетической.
2. **Совпадение с эталоном — 976 из 1028 точных совпадений (94,94 %)**, ещё
   одна граница в пределах 5 кадров. 52 эталонные границы нашлись бы при
   пороге ниже 4; 138 наших границ человек в старом проекте не оставил.
3. **Объём по архиву подтверждён**: 71 005 сегментов на 73 эпизоде, разрывов нет
   нигде (замер T039, PR #15).
4. **Карта ключевых кадров совпала** с признаком `isIFrame` по 792 номерам,
   расхождений 0 (замер T040, PR #15).

Числа 94,94 % **не** являются оценкой качества разметки: они меряют согласие
с решениями человека, принятыми в другом проекте, другим человеком и в другое
время. Качество разметки меряет критерий SC-003, см.
[отчёт о доле принятых границ](sc-003-boundary-acceptance.md).

## Что это означает для дальнейшей работы

1. **Порог 4 — рабочая точка.** Наибольшее совпадение с эталоном достигается
   при значении, которое уже стоит в настройках по умолчанию. Рост порога
   убирает границы, которые человек считал нужными, а не добавляет точности.
2. **52 «не найденные» границы — материал для ручной доводки.** Это места, где
   человек в старом проекте поставил границу, а оценка сходства была ниже
   порога. Именно их оператор увидит на экране структуры как пропуски.
3. **138 «лишних» границ — материал для автоматического склеивания планов.** В
   старом проекте их склеили вручную; в нашей системе это делает редактор
   (FR-013), и объём работы оператора на первом эпизоде будет понятен по этому
   числу.
4. **Сверка сцен невозможна принципиально**, пока в старом проекте нет границ
   сцен. Число 46 названных сцен использовать как эталон нельзя.

## Ограничения сверки

1. **Один прогон детекции.** На границы это не влияет — считается по
   сохранённому выводу, — но время 152 с не имеет разброса.
2. **Совпадение считается по номеру кадра.** Кадр монтажной склейки и кадр,
   вычисленный по оценке сходства, могут отличаться на кадр при одном и том же
   смысле; доля «в пределах 5 кадров» приведена рядом.
3. **Эталон — другой проект и другая нумерация.** Сдвиг на единицу учтён, но
   сам факт сдвига означает, что одно расхождение возможно на любой границе.
4. **Прогон с агентской машины**, не из контейнера.
