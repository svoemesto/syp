# Контракт: HTTP API публичной части (`syp-public-app`)

**Feature**: 001-first-vertical-slice
**Потребитель**: `syp-public-web` (Vue 3) и только он.
**Транспорт**: HTTP/1.1, JSON, префикс `/api`. Аутентификации в первый срез
нет — стек локальный, публикация в интернет не планируется.

## 1. Граница ответственности

Публичная часть **показывает результат** и **инициирует сборку**. Здесь нет
разметки, обучения моделей, справочника локаций и любых настроек
(`docs/domains/showcase/domain.md`, инварианты 1 и 2; Hard Gate
«Двух-фронтенд»).

| Есть в публичной части | Нет в публичной части |
|---|---|
| список сериалов | создание и правка сериалов |
| список и применение сохранённых фильтров | редактор дерева условий |
| выбор сцен | доводка границ, отмена решений алгоритма |
| запуск сборки и наблюдение за заданием | обучение и версии моделей |
| просмотр готового видео | рисование лиц, назначение персон |
| — | операторские задания любого вида |

Аутентификации нет, поэтому «нет в публичной части» обеспечивается **отсутствием
эндпоинта**, а не проверкой прав: эндпоинт, которого нет, вызвать нельзя.

## 2. Общие правила

Коды ответов, формат тела ошибки, пагинация и нумерация кадров — общие с
админкой и описаны в
[`admin-api.md`](admin-api.md), раздел 1. Здесь действуют те же правила.

Специфичный код ошибки этого контейнера:

| Код | Когда | Ответ |
|---|---|---|
| `INCOMPATIBLE_SERIES` | серии подборки несовместимы для склейки без перекодирования | `422` с перечнем серий и различающимися признаками |
| `ASSEMBLY_NOT_READY` | подборка ещё не собрана или сборка failed | `409` с состоянием |
| `SOURCE_UNREADABLE` | файл серии недоступен | `422` до начала работы |

## 3. Сериалы и фильтры

| Метод | Путь | Назначение | FR |
|---|---|---|---|
| `GET` | `/api/serials` | сериалы, у которых есть размеченные данные | FR-084 |
| `GET` | `/api/serials/{serialId}/filters` | сохранённые фильтры: имя, условие, число подходящих сцен | FR-084 |
| `POST` | `/api/filters/{filterId}/apply` | применить фильтр, получить список сцен | FR-071, FR-084 |

Пользователь видит **условие фильтра текстом**, а не деревом: «Джейми
Ланистер, крупный план, место действия — Лагерь Джейми». Формулировка
собирается на бэкенде из того же дерева, по которому фильтр исполняется, —
расхождение между надписью и результатом невозможно по построению.

Тело `POST /api/filters/{filterId}/apply`:

```json
{
  "filterName": "Джейми в лагере, крупно",
  "formula": "персона «Джейми Ланистер» И место действия «Лагерь Джейми» И размер плана один из CU, BCU",
  "sceneCount": 37,
  "totalDurationMs": 412000
}
```

Сцены возвращаются отдельным запросом с пагинацией:

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/api/filters/{filterId}/scenes` | сцены по фильтру: серия, границы, планы, персонажи, место действия |
| `GET` | `/api/series/{seriesId}/scenes/{sceneId}/preview` | превью сцены для выбора |

## 4. Подборка и сборка

**Инициатор сборки — пользователь** (FR-085). Оператор в админке подготавливает
данные, но подборку за пользователя не собирает.

| Метод | Путь | Назначение | FR |
|---|---|---|---|
| `POST` | `/api/assemblies` | создать подборку из выбранных сцен | FR-084, FR-086 |
| `GET` | `/api/assemblies/{assemblyId}` | состояние подборки, прогресс, результат | FR-088 |
| `GET` | `/api/assemblies` | мои подборки | FR-088 |
| `GET` | `/api/assemblies/{assemblyId}/video` | воспроизведение собранного файла | FR-084 |
| `GET` | `/api/assemblies/{assemblyId}/manifest` | список вошедших сцен | FR-084 |

### 4.1 Создание подборки

`POST /api/assemblies` — тело `{"name": "Джейми — выходы", "sceneIds": [1, 4, 9]}`.

**Проверка совместимости выполняется до создания задания** (FR-087). Если
разрешение, кодек, профиль, формат пикселей, частокадровая база или параметры
аудио различаются, ответ `422`:

```json
{
  "code": "INCOMPATIBLE_SERIES",
  "message": "Сборка отменена: серии несовместимы для склейки без перекодирования",
  "details": {
    "differingAttributes": ["videoProfile", "pixelFormat"],
    "series": [
      {"seriesId": 7, "name": "GOT.S01E01", "videoProfile": "High", "pixelFormat": "yuv420p"},
      {"seriesId": 8, "name": "GOT.S01E02", "videoProfile": "Main", "pixelFormat": "yuv420p"}
    ]
  }
}
```

Сценарий спецификации требует именно такого поведения: **молча ухудшать
качество нельзя**, а падать на середине работы — тоже. Проверка идёт по
метаданным, сохранённым при приёме серий, дополнительных проходов по видео не
требует.

Успешный ответ — `202`:

```json
{
  "assemblyId": 55,
  "state": "CREATING",
  "jobId": 900,
  "expectedDurationMs": 412000,
  "expectedFrameCount": 9876
}
```

### 4.2 Наблюдение за заданием

`GET /api/assemblies/{assemblyId}`:

```json
{
  "id": 55,
  "name": "Джейми — выходы",
  "state": "WORKING",
  "progress": {"done": 31, "total": 37, "note": "фрагмент 31 из 37"},
  "expectedDurationMs": 412000,
  "actualDurationMs": null,
  "expectedFrameCount": 9876,
  "actualFrameCount": null,
  "scenes": 37,
  "videoReady": false
}
```

Повторное открытие страницы **не теряет** задание: состояние читается из
хранилища по адресу подборки, а не из состояния вкладки браузера
(крайний случай спецификации, FR-088).

### 4.3 Длительности

Когда сборка завершена, ответ содержит **обе** длительности (FR-083):

```json
{
  "state": "DONE",
  "expectedDurationMs": 412000,
  "actualDurationMs": 416583,
  "expectedFrameCount": 9876,
  "actualFrameCount": 9960,
  "difference": {"durationMs": 4583, "frames": 84, "cause": "округление границ до ключевых кадров при склейке без перекодирования"}
}
```

Расхождение — ожидаемое следствие склейки без перекодирования, а не дефект
(ADR-0006, FR-082). Интерфейс показывает обе величины всегда, когда они
разошлись; расчётная показывается как «ожидалось», фактическая — как
«получилось», с указанием причины расхождения.

### 4.4 Манифест и видео

`GET /api/assemblies/{assemblyId}/manifest` — список вошедших сцен с фактическими
границами фрагментов:

```json
{
  "assemblyId": 55,
  "items": [
    {"ordinal": 1, "sceneId": 1, "seriesId": 7, "seriesName": "GOT.S01E01",
     "expectedFirstFrame": 1200, "expectedLastFrame": 1455,
     "actualFirstFrame": 1188, "actualLastFrame": 1460}
  ]
}
```

`actualFirstFrame` отличается от расчётного, когда граница округлилась до
ключевого кадра: ровно то самое расхождение, которое объясняется пользователю
(FR-082).

`GET /api/assemblies/{assemblyId}/video` отдаёт собранный файл с поддержкой
воспроизведения по диапазону. Возвращается **только** артефакт в состоянии
`READY`: незавершённый файл не считается готовым (FR-091).

## 5. Устойчивость цикла

Требования SC-004, SC-008, SC-010 проверяются этим циклом целиком:

1. пользователь открывает сериал и видит сохранённые фильтры;
2. применяет фильтр одним действием и получает список сцен (SC-007);
3. отмечает сцены и запускает сборку;
4. видит задание с прогрессом; перезагрузка страницы ничего не теряет
   (FR-088);
5. после завершения воспроизводит видео целиком, без пропусков (SC-008);
6. видит список вошедших сцен и обе длительности (FR-084, FR-083);
7. ни разу не обращается к оператору (SC-010).

## 6. Что в контракт не входит

- Разметка, доводка, обучение, настройки — по разделу 1.
- Скачивание файла отдельной кнопкой в первом срез не входит: воспроизведение
  и манифест закрывают сценарий FR-084. Скачивание — естественное
  продолжение, но в объём среза не заявлено.
- Рекомендации и подборки «похожих сцен» — вне объёма.
